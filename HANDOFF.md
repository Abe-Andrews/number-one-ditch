# Handoff: Journey to the Number One Ditch

A browser-based, GBA/Minish Cap-style Zelda game made as a gift for the user's family,
full of family inside jokes. Nate is the hero; Father Eggmas is the villain.

- **Live link (share with family):** https://abe-andrews.github.io/number-one-ditch/
- **Repo:** https://github.com/Abe-Andrews/number-one-ditch (public), local at `~/Desktop/number-one-ditch`
- **Branch:** `game-engine-first-area` (the only branch; GitHub Pages deploys from it, `/` root)
- **Reference photos:** `~/Desktop/Refe Photos/` (HEIC/PNG: Abe, Doron and Lily, Hannah, Christian Dad, Nate, Father Eggmas)
- **Tech:** plain HTML5 canvas + classic `<script>` files, no build step, no dependencies. 240x160 internal resolution, integer-scaled. All art is generated in code. All music is original chiptune via WebAudio.

## Running and testing locally

```bash
cd ~/Desktop/number-one-ditch && python3 -m http.server 8123
```

Open `http://localhost:8123/?v=N` in the built-in browser (`preview_start` with a `url`; the `.claude/launch.json` route doesn't work because the preview tool looks at the old scratch folder). The browser pane is usually hidden, which **pauses requestAnimationFrame**, so drive the game manually from `javascript_tool`:

```js
const ctx = document.getElementById('screen').getContext('2d');
window.run = (n=1) => { for (let i=0;i<n;i++){ G.tick++; G.scene.update(); G.input.endTick(); } G.scene.draw(ctx); };
window.key = (code, ticks=2) => { dispatchEvent(new KeyboardEvent('keydown',{code})); run(ticks); dispatchEvent(new KeyboardEvent('keyup',{code})); run(1); };
// jump anywhere with a crafted state:
const s = G.debug.newState(); Object.assign(s.items, {hammer:true, cap:true}); Object.assign(s.flags, {readChat:true});
s.map = 'campus'; s.x = 20*16; s.y = 22*16+14; s.dir = 'down'; G.state = s; G.play.enter(false); run(40);
```

- Speed through dialogue: set `G.script.cur.cmd.chars = 999; .wait = 0`, then `key('KeyZ')`.
- Screenshots need the pane shown (`mcp__ccd_view__show_pane` with `preview`).
- The browser caches scripts aggressively; navigate with a new `?v=` or `fetch(url, {cache:'reload'})` then reload.
- `node` is not installed (no syntax check); test in the browser and read console errors.

Controls: Arrows/WASD move, Z swing/talk/confirm, X use the item on X, Enter menu (Q/E switch tabs), M mute.

## Code map (`src/`, ~5.8k lines)

| File | Contents |
| --- | --- |
| `core.js` | `G` namespace, seeded RNG/hash, input (`G.input.hit/down/eat`, buttons `a b start l r up down left right`), audio (SFX list + tiny tracker `G.audio.play(song)`) |
| `font.js` | Hand-made bitmap font, color codes in text like `{y}yellow{/}` (`w k r b g y p o v d c`), word wrap, `drawBig` for titles |
| `art.js` | Pixel buffer `Pix` with auto-outline; **person generator** `G.art.person(cfg)` (all humans); tiles (`TILE_DRAW`); props (trees, buildings w/ banner, lab furniture, cars, stands, booth, ring, boulder, gift, icons...); `G.spr.*` registry built in `G.art.init()` |
| `world.js` | Maps: tile defs `G.TILE_DEFS` (char → kind/solid/edge/group), props, triggers/warps, collision with corner-nudge, y-sorted drawing, particles `burst`, floating text `pop`, glow lights, optional map `tick` hook |
| `entities.js` | Player (hammer swing, hurt, hold pose), NPC, Follower (party trailing Nate), Six, Wrestler, ElEnglish (boss), Letter (boss projectile), Package (bomb), Pickup, Chest, Sign, Boulder, FerrisWheel, LightString |
| `script.js` | Generator-based cutscene runner `G.script.run(gen)`; commands `G.say/ask/text(phone style)/wait/fadeIn/fadeOut/emote/walkTo/itemGet/banner/shakeCmd/camFocus`; name tag colors `G.NAME_COLORS` |
| `ui.js` | HUD (hearts, X/Z boxes, shark teeth), boss health bar, area banner, **tabbed pause menu** (ITEMS / KEY ITEMS / PEOPLE / JOURNAL). PEOPLE lists the party plus key characters met (`CHARACTERS` + `G.people()` in content.js) and scrolls |
| `content.js` | **Everything story:** `G.CAST` (sprite configs), `G.ITEMS` registry + `GEAR_SLOTS`/`KEY_SLOTS`, `G.PARTY_INFO`, `G.journal()` goal tracker, `G.SONGS`, `G.SCRIPTS` (all dialogue), `G.MAPS` |
| `main.js` | State (`newState`), save/load (`localStorage` key `number-one-ditch-save-v1`, autosave on every warp), play scene (camera, triggers, trail, explode, items, drops), title, intro, game over, loop |

Patterns:
- **New character:** add a config to `G.CAST` (options: skin, hair, hairStyle `short/swoop/buzz/receding/cropped/cap/long/wavy/shoulder`, hat+hatStyle `flat/ball`, patch, shirt, pattern `plaid/floral/stripes`, collar, neck, neckline, necklace, coat, cloak/hood, dress, beltStrap, pants, shorts, shoes, boots, glasses, beard, earring, blush, smile, mask+maskTrim+maskEmblem, wide, torso, legs).
- **New map:** `G.MAPS.id = { name, music, tiles: rows | () => rows, setup(w), onEnter?(), tick?(w), tint?(ctx) }`. Use `w.addBuilding`, `w.addProp`, `w.add(entity)`, `w.addWarp(tx,ty,w,h, map, tx,ty, dir)`, `w.addTrigger(...)`, `w.blockTiles(...)`. `'T'` in tiles = 2x2 tree.
- **New item:** one entry in `G.ITEMS` (`kind 'gear'|'key'`, `equip`, `use`, `has()`, `count()`, `short`) + a slot in `GEAR_SLOTS`/`KEY_SLOTS`. X-item behavior lives in `G.play.useItem`.
- Talking to an NPC first checks `S.ticketReaction` (Doron's ticket quest), then runs `npc.talk`.
